
# Offline AI Agent

An offline AI Agent built using Llama 3.1, Ollama, ChromaDB and Streamlit.

## Features

- Local LLM using Ollama
- Tool Calling
- Retrieval-Augmented Generation (RAG)
- PDF Upload
- ChromaDB Vector Database
- Calculator Tool
- Dataset Inspector
- Chat Memory
- Streamlit UI
